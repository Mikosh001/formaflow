# FormaFlow

**Google Forms жауаптарын дайындауға, тексеруге және басқаруға арналған үш тілді жұмыс орны.**

## Қолдану

1. **Форманы қос.** Google Forms жауап беру сілтемесін енгізіп, **«Сұрақтарды оқу»** түймесін бас.
2. **Өз жауаптарыңды жаз.** Әр сұрақты ашып, нұсқаларды белгіле. Мәтіндік сұраққа өз жауабыңды жаз.
3. **Санын таңда.** Бір іске қосуда **1–100 жауап**. Жауаптар арасындағы үзіліс: 2, 3, 5 немесе 10 секунд.
4. **Алдын ала қара.** **«Жауаптарды дайындау»** түймесін бас. Қарындаш белгісі арқылы жеке жолды өңде. CSV немесе JSON жүктеп алуға болады.
5. **Іске қос.** **«Жіберу»** жауаптарды кезекпен жібереді. **«Тоқтату»** ағымдағы сұрау аяқталған соң тоқтатады. Қалған дайын жауаптарды кейін жалғастыра аласың; қабылданғандары қайта жіберілмейді.

**Екі режим:** «Әр жолы әртүрлі» белгіленген нұсқалардан таңдайды және мәтіннің әр жолын кезекпен қолданады. «Бірдей жауаптар» толық мәтінді жол үзілістерімен бірге өзгеріссіз қолданады. Автоматты сөздер мен белгілер қосылмайды.

Жоғарғы мәзірден **Қазақша / Русский / English** таңда. Тіл сақталады. Google Form сұрақтары түпнұсқа тілінде қалады.

## Сақтау және файлдар

- **Осы құрылғыға сақтау:** форма, жауаптар және параметрлер осы браузерге жазылып, қайта ашқанда қалпына келеді.
- **Жобаны жүктеу / Жобаны ашу:** жобаны JSON арқылы басқа құрылғыға ауыстыру.
- **CSV / JSON:** дайын жауаптар мен олардың күйлерін жүктеу.
- **Тарих:** уақыт, атау және қабылданған жауап саны сақталады; жауап мәтіндері тарихқа жазылмайды.

Жоба файлының ішінде өз жауаптарың бар. Оны бөліскенде мазмұнын ескер.

## Қолдау және нәтиже

Ашық, бір бөлімді формалар: қысқа мәтін, абзац, бір нұсқа, ашылмалы тізім, бірнеше нұсқа және қарапайым шкала. Бірнеше нұсқаның санына қойылған шек сақталады.

Кіру, CAPTCHA, email жинау, файл, күн/уақыт, сұрақтар торы, шартты бөлімдер және қосымша тексеру ережелері қолдау таппайды. Google Forms құрылымы өзгерсе, парсерді жаңарту қажет болуы мүмкін.

**«Қабылданды»** тек Google растау бетін бергенде көрсетіледі. Байланыс үзілсе не нәтиже анық болмаса, **«Расталмады»** көрсетіліп, кезек тоқтайды. Қайта жібермес бұрын Google Forms нәтижелерін тексер. Сервердегі қайталаудан қорғау бір процестің уақытша жадында жұмыс істейді; сервер қайта іске қосылғанда ол сақталмайды.

## Компьютерде іске қосу

**Node.js 22.17+** және npm қажет.

```sh
git clone https://github.com/Mikosh001/formaflow.git
cd formaflow
npm ci
```

Екі терминал аш:

```sh
# 1-терминал: API, http://127.0.0.1:8787
npm run dev:api
```

```sh
# 2-терминал: интерфейс, http://127.0.0.1:5174
npm run dev
```

Тексеру және жинау:

```sh
npm run typecheck
npm test
npm run build
npm run build:api
```

Тексерулер Google-ға жауап жібермейді: сервер жауаптары имитацияланады.

## GitHub Pages және сервер

GitHub Pages интерфейсті `main` тармағының **`/docs`** бумасынан жариялайды. Google Forms сұрауларын бөлек Node.js API орындайды; Pages серверлік кодты орындамайды.

1. API мекенжайы: `lib/deployment.json` → `apiUrl`.
2. Өзгерістерден кейін `npm run pages:prepare` орында. Бұл `/formaflow/` жолына сәйкес статикалық файлдарды `docs/` бумасына жинайды.
3. Бастапқы код пен `docs/` өзгерістерін GitHub-қа жүкте.
4. GitHub → **Settings → Pages → Deploy from a branch → main → /docs → Save**.

Басқа репозиторий атымен қолдансаң, `scripts/prepare-pages.mjs` ішіндегі `PAGES_BASE` мәнін өзгерт.

### Render API

- Runtime: **Node**; Build: `npm ci --include=dev && npm run build:api`; Start: `npm start`.
- `NODE_VERSION=22.17.0`
- `ALLOWED_ORIGINS=https://mikosh001.github.io`
- Сервер `0.0.0.0` және Render берген `PORT` портын тыңдайды.
- Күйін тексеру: `GET /health`.
- Клиенттер: `POST /api/forms`; әрекеттері: `inspect`, `submit`.

CORS браузер мекенжайларын шектейді; ол пайдаланушыны аутентификациялау жүйесі емес. API жауаптарды тұрақты дерекқорға жазбайды. Тегін Render сервері бос тұрғанда ұйықтап, алғашқы сұрауда оянуы мүмкін: [Render шектеулері](https://render.com/docs/free).
