# FormaFlow

**Трёхъязычное рабочее пространство для подготовки, проверки и управления ответами Google Forms.**

[Қазақша](README.md) · [Русский](README.ru.md) · [English](README.en.md)

[Открыть сайт](https://mikosh001.github.io/formaflow/)

## Как пользоваться

1. Вставь ссылку для заполнения Google Forms и нажми **«Прочитать вопросы»**.
2. Открой каждый вопрос, отметь варианты и напиши свои текстовые ответы.
3. Выбери **1–100 ответов** и паузу 2, 3, 5 или 10 секунд.
4. Нажми **«Подготовить ответы»**. Редактируй строки значком карандаша; скачивай CSV или JSON.
5. **«Отправить»** запускает очередь. **«Остановить»** завершает текущий запрос. Оставшиеся ответы можно продолжить без повторной отправки принятых.

В режиме **разных ответов** используются отмеченные варианты и строки текста по очереди. В режиме **одинаковых ответов** весь текст, включая переносы строк, используется без изменений. Дополнительные слова и метки не добавляются.

Переключай интерфейс, инструкцию и ошибки между **қазақша / русский / English**. Вопросы формы сохраняют исходный язык.

## Сохранение

**Сохранить на устройстве** записывает проект в браузер и восстанавливает его при следующем открытии. **Скачать проект / Открыть проект** переносит форму, ответы и параметры через JSON. История хранит время, название и принятый счётчик, без текстов ответов. Файл проекта содержит твои ответы — учитывай это при передаче другим.

## Поддержка и результаты

Открытые односекционные формы: текст, абзац, одиночный выбор, выпадающий список, множественный выбор и простая шкала. Ограничение числа отмеченных вариантов соблюдается.

Не поддерживаются вход, CAPTCHA, сбор email, файлы, даты/время, сетки, условные разделы и дополнительные правила валидации. Парсер зависит от структуры Google Forms и может потребовать обновления.

**«Принято»** означает подтверждение Google. При обрыве связи или неизвестном результате появляется **«Не подтверждено»**, очередь останавливается. Проверь Google Forms перед повтором. Защита от повторов находится в памяти одного серверного процесса и сбрасывается при перезапуске.

## Локальный запуск

Нужны **Node.js 22.17+** и npm.

```sh
git clone https://github.com/Mikosh001/formaflow.git
cd formaflow
npm ci
npm run dev:api
```

Во втором терминале:

```sh
npm run dev
```

Интерфейс: `http://127.0.0.1:5174`; API: `http://127.0.0.1:8787`.

```sh
npm run typecheck
npm test
npm run build
npm run build:api
```

Проверки имитируют ответы сервера и ничего не отправляют в Google.

## Размещение

Pages публикует **`main /docs`**. API работает отдельно: Pages обслуживает статические файлы.

- API: `lib/deployment.json` → `apiUrl`.
- Выполни `npm run pages:prepare`; закоммить исходники и `docs/`.
- GitHub → Settings → Pages → Deploy from a branch → main → /docs → Save.
- Для другого имени репозитория измени `PAGES_BASE` в `scripts/prepare-pages.mjs`.

Render: Node; Build `npm ci --include=dev && npm run build:api`; Start `npm start`; `NODE_VERSION=22.17.0`; `ALLOWED_ORIGINS=https://mikosh001.github.io`. Сервер слушает `0.0.0.0` и `PORT`, состояние — `/health`.

CORS ограничивает браузерные источники и не заменяет аутентификацию. API не сохраняет ответы в базу. Бесплатный сервер может просыпаться после простоя: [ограничения Render](https://render.com/docs/free).

## Структура

`app/` — интерфейс; `lib/` — форма, ответы, языки, проекты и API; `server/` — Node.js; `tests/` — проверки; `scripts/` — подготовка Pages; `docs/` — публикация. React, TypeScript, Vite. API-ключи не нужны. Это не официальный продукт Google.
